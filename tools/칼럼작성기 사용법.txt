디어한의원 칼럼 작성기

1. 프로젝트 폴더의 "칼럼작성기 열기.cmd"를 더블클릭합니다.
2. 검은 창은 에디터를 실행하는 창입니다. 글을 쓰는 동안 닫지 않습니다.
3. 브라우저가 열리면 왼쪽에서 제목과 본문을 씁니다.
4. 오른쪽 LIVE 화면에 실제 디어 칼럼 디자인이 바로 반영됩니다.
5. PC·모바일 버튼으로 두 화면을 번갈아 확인할 수 있습니다.

본문 도구

- 소제목: 왼쪽 고정 목차에 자동으로 들어갑니다.
- 굵게: 선택한 문장을 강조합니다.
- 목록: 여러 항목을 차례로 설명할 때 사용합니다.
- 인용: 기억시키고 싶은 짧은 문장에 사용합니다.
- 링크: 확인한 외부 자료로 연결할 때 사용합니다.

화면 구성

- 큰 소제목과 설명: MEDICAL BASIS 같은 큰 초록색 제목입니다.
- 확인 항목 표: WHAT WE CHECK 좌우 표입니다.
- 경우별 번호 카드: POSSIBLE PATHS 번호 카드입니다.
- 진한 핵심 문장: KEY POINT 초록색 상자입니다.
- 본문 사진: 글 중간에 사진과 설명을 넣습니다.
- 각 구성의 ↑·↓ 버튼으로 순서를 바꾸고 × 버튼으로 삭제합니다.
- 본문 소제목과 화면 구성의 큰 제목은 왼쪽 고정 목차에 자동으로 들어갑니다.

저장과 발행

- 임시 저장: 이 컴퓨터의 비공개 전용 폴더에 저장합니다. 홈페이지에는 공개되지 않습니다.
- 미리보기 만들기: 실제 발행기와 동일한 HTML 미리보기를 만듭니다. 검색과 칼럼 목록에는 공개되지 않습니다.
- 홈페이지에 발행: 확인창을 거친 뒤 완성된 글과 그 글의 사진만 GitHub Pages에 게시합니다.
- 대표 사진, 영문 주소, 분류, 글쓴이, 게시일은 "글 설정과 검색 정보"를 열어 입력합니다.

주의

- 치료 효과를 보장하거나 단정하는 표현, 환자 후기, 전후 사진을 사용하지 않습니다.
- 게시 전 원고와 참고 자료를 최종 확인합니다.
- 환자 개인정보를 본문·사진·FAQ에 넣지 않습니다.
- 작성기는 비밀번호나 GitHub 로그인 정보를 저장하지 않습니다.
