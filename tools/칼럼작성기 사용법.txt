디어한의원 칼럼 작성기

1. 프로젝트 폴더의 "칼럼작성기 열기.cmd"를 더블클릭합니다.
2. 검은 창은 작성기를 실행하는 창이므로 글을 쓰는 동안 닫지 않습니다.
3. 중앙 원고지에서 제목, 소개 문장, 본문을 씁니다.
4. 오른쪽 위 "미리보기"에서 PC·모바일 홈페이지 모습을 확인합니다.
5. "검토하고 공개"에서 분류, 글쓴이, 대표 사진, FAQ, 참고 자료를 입력합니다.

두 가지 글쓰기

- 기본 글쓰기: 네이버 블로그처럼 보이는 화면에서 바로 작성하고 꾸밉니다.
- HTML: AI가 만든 본문용 HTML을 붙여 넣습니다. "기본 글쓰기"로 돌아오면 적용된 모습을 바로 확인할 수 있습니다.
- HTML에는 본문 내용만 넣습니다. 목차, 상담 안내, FAQ, 병원 주소와 전화번호는 발행할 때 자동으로 붙습니다.

위쪽 넣기 도구

- 사진: 본문 중간에 사진과 설명을 넣습니다. JPG·PNG·WebP, 5MB 이하를 사용합니다.
- 소제목: 홈페이지 왼쪽 목차에 자동으로 들어갑니다.
- 인용·핵심문장·목록·구분선: 선택한 위치에 해당 모양을 넣습니다.
- 표: 원고 좌우 폭에 맞는 3열 기본 표를 넣습니다. 셀을 사각형으로 드래그해 여러 칸을 선택하고 병합하거나, 병합된 셀을 다시 분리할 수 있습니다. 셀 오른쪽·아래쪽 경계를 드래그하면 열 너비와 행 높이가 바뀝니다.
- 제목 줄과 본문 줄은 서로 병합할 수 없습니다. 표 모양이 예상과 달라지면 셀을 누르고 `표 작업 취소`를 사용합니다. 이미 여러 번 병합해 골격이 흐트러졌다면 `모든 병합 해제`로 표를 직사각형 형태로 복구합니다.
- 표 색상: 선택한 셀에만 `셀 배경색`과 `글자색`을 각각 적용합니다. 프리셋 색상표 또는 채도·명도 영역과 색상 계열 슬라이더에서 눈으로 색을 고릅니다.
- 글자 도구: 11~38px 글자 크기, 굵게, 기울임, 밑줄, 취소선, 정렬, 목록, 링크, 글자색, 배경색을 바꿉니다.
- 색상값을 정확히 알고 있다면 팔레트 아래 `#247860` 칸에 HEX 값을 직접 입력하고 Enter 또는 확인을 누릅니다.

저장과 공개

- 글은 입력 뒤 약 0.5초 후 이 브라우저에 자동 저장됩니다.
- 저장: 이 컴퓨터의 비공개 `.column-editor` 폴더에 초안 JSON을 저장합니다. 대표 사진이 없어도 됩니다.
- 미리보기: 실제 발행기와 같은 홈페이지 HTML을 만듭니다. 검색과 칼럼 목록에는 공개되지 않으며 대표 사진이 필요합니다.
- 홈페이지에 공개: 확인창을 거쳐 완성 글, 목록 카드, sitemap, 글 전용 사진을 GitHub Pages에 게시합니다.
- FAQ는 자동으로 만들지 않습니다. `검토하고 공개` 패널에서 직접 추가한 질문이 있을 때만 글 마지막에 표시됩니다.

주의

- 치료 효과를 보장하거나 단정하는 표현, 환자 후기, 전후 사진을 사용하지 않습니다.
- 게시 전 원고와 참고 자료를 최종 확인합니다.
- 환자 개인정보를 본문·사진·FAQ에 넣지 않습니다.
- 작성기는 비밀번호나 GitHub 로그인 정보를 저장하지 않습니다.
